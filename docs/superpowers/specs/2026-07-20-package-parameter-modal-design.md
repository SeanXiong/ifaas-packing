# 打包参数弹窗设计

## 目标

将一次性打包参数从右侧组件配置区域集中到“开始打包”后的表单式弹窗中，降低参数与业务组件选择混杂造成的误操作。

## 弹窗字段与默认值

点击“开始打包”后显示“打包参数”弹窗，字段如下：

| 字段 | 默认值 | 可选值 |
| --- | --- | --- |
| 包类型 | 安装包 | 安装包、升级包 |
| 网络类型 | 离线 | 离线、在线 |
| CPU 架构 | `x86_64` | `x86_64`、`aarch64` |
| 命名空间 | `basic-app` | 用户输入 |
| 上传云盘 | 关闭 | 开关 |

## 联动与提交

网络类型为在线时，上传云盘开关自动关闭并禁用；离线时允许用户切换。点击“下一步”后进入现有二次确认弹窗，确认弹窗展示上述全部参数及已选组件和分支。

提交时使用弹窗中的参数，并对每个组件固定传递 `need_apollo: true`，不再展示或读取 Apollo 数据库配置。

## 右侧页面调整

移除右侧“全局参数”区域。右侧仅保留业务组件选择、搜索和开始打包操作。

## 验证

测试覆盖默认参数、表单选择值的提交传递、在线包禁用云盘上传、所有模块固定提交 `need_apollo: true`。
