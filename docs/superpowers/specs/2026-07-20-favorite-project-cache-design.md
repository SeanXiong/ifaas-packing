# 收藏项目详情缓存设计

## 目标

收藏项目直接保存左侧渲染所需的项目对象，登录后从本地配置读取并渲染，不再为每个收藏项目重复请求项目详情接口。

## 数据结构

每个账号在 `config/favorites.json` 中保存项目对象列表：

```json
{
  "accounts": {
    "alice": {
      "projects": [
        { "id": 345, "name": "项目名称" }
      ]
    }
  }
}
```

收藏状态仍以项目对象中的 `id` 或 `pk` 作为唯一标识。

## 兼容与更新

历史 `project_ids` 结构在首次登录时逐个请求项目详情，成功结果写入 `projects` 并覆盖旧结构；此补全仅执行一次。新增收藏时直接保存当前项目对象，取消收藏时删除对应项目对象。

## 请求规则

登录后仅读取 `favorites.json` 并渲染收藏列表。点击收藏项目时始终调用版本接口，获取实时版本数据；版本数据不写入收藏缓存。

## 验证

测试覆盖：对象缓存直接读取、旧 ID 一次性补全、收藏增删同步更新缓存、登录后已有对象缓存不调用项目详情接口。
