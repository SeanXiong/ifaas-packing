# 登录账号本地保存设计

## 目标

个人部署场景下，用户登录成功后，将本次登录的账号和密码保存至服务端本地配置文件。后续以 `?profile=<登录名>` 访问时，登录页自动预填对应账号和密码。

## 配置结构

配置文件为 `config/login-profiles.json`，以登录名作为唯一键：

```json
{
  "accounts": {
    "alice": {
      "username": "alice",
      "password": "密码"
    }
  }
}
```

同一登录名再次登录时，覆盖该账号原有记录。

## 流程

1. 用户输入账号和密码并通过登录接口认证。
2. 前端在不影响当前登录会话的前提下，将账号和密码写入 `login-profiles` 配置。
3. 写入成功后进入业务页面；写入失败时仍进入业务页面，并明确提示账号信息未保存。
4. 未登录访问 `?profile=alice` 时，前端读取对应记录并预填登录表单。
5. 无对应记录、配置文件缺失或配置格式异常时，保持表单为空，允许手动登录。

## 安全边界

密码不会写入 URL、日志或页面提示，仅保存于本机服务端的 JSON 文件。该设计仅适用于个人受控部署环境；部署时应限制 `config/login-profiles.json` 的访问权限。

## 验证

新增测试覆盖：登录成功后写入当前账号与密码、同名账号覆盖旧记录、配置写入失败不阻断登录。
